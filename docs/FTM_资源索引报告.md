## 二、⚠️ 最重要的结论：中文独立站点生态本身稀薄

本轮派出专门的检索线（约 28 组检索 + 逐站实访）去找「已收录之外、存活、网友自建、含中文」的**独立站点**，结果：

**合格新站点只有 1 个，且我无法独立复核它能否访问。**

这不是检索疏漏，是生态事实——中文跨性别内容主要沉淀在三类载体上，而这三类**都不符合「独立站点」形态**：

| 载体 | 现状 | 举例 |
|---|---|---|
| **微信公众号** | 内容质量最高，但无长期可引用链接 | 无界心屿、G0SSIP、跨儿文化 —— 见第六节 |
| **注册 NGO / 机构** | 有官网、内容成体系，但按你的口径要排除 | 北京同志中心、出色伙伴、跨之声、爱白网、跨儿心理 |
| **开源仓库 / Wiki** | 已收录充分（Project Trans 一整套） | mtf.wiki、rle.wiki、ftm.wiki |

**换句话说：中文跨性别领域里「个人自建独立网站」这种形态几乎没有存活样本。** 值得注意的历史样本也基本都死了（见第五节）。

## 三、⚠️ 确认的三个硬缺口：FTM 用药 / 嗓音 / 手术

### 3.1 中文 HRT 站点出现了，但全部是女性化（MtF）方向

补检索找到 3 个中文 HRT 资源站（本轮已收录，见第五节），但**逐一实测关键词分布后确认它们都以女性化治疗为主**：

| 站点 | 雌二醇 | 睾酮 | 男性化 |
|---|---|---|---|
| `luluv.wiki/zh/HRTMeds` | 42 次 | 28 次 | **1 次** |
| `hrtyaku.com/zh` | 4 次 | 0 次 | 0 次 |

> `luluv.wiki` 虽然提及睾酮 28 次，但「男性化」仅 1 次，主体仍是抗雄+雌激素方案。**FTM 男性化用药的中文独立资料站依然为零。**

### 3.2 FTM 嗓音男性化 = 0

专项检索确认：**找不到任何专门针对 FTM 声音男性化的中文站点。** 现有中文嗓音资源全部是女性化方向：

| 资源 | 方向 | 状态 |
|---|---|---|
| `vocal.mtf.wiki` | MTF 女性化 | 在线，Project Trans 维护 |
| `trans-archive/jyosei-guide`（71★） | MTF 女性化 | 停更 2023-11 |
| `theforeveriris/simple-voice-tools` | 通用工具（音高检测） | 在线，男女方向均可用 |

搜到的其余中文内容只是通用「伪声／配音」教程，不针对跨性别。**这个缺口目前无人填补。**

### 3.3 FTM 手术资料中文侧 = 0

中文自建的手术资料站不存在，只能依赖英文源（`topsurgery.net`、`phallo.net`）。

**三个缺口的共同点**：都集中在 FTM 侧，且都没有人占据。

## 九、行业格局总结

1. **知识整合层很强** —— Project Trans 一个组织撑起 mtf.wiki（1084★）、rle.wiki（261★）、ftm.wiki（16★）、tfsci 中文翻译、RIME 词典、用户报告，主题开源可复用。

3. **三个确认的空白（全在 FTM 侧）**：
   - **HRT 男性化用药** —— 中文站点已出现 3 个，但**清一色女性化方向**；FTM 男性化用药的中文独立资料站为零
   - **FTM 嗓音男性化** —— 完全为 0
   - **FTM 手术资料** —— 中文侧为 0，只有英文站
4. **判断**：中文跨性别资源在「知识整合」上做得很好，MTF 侧的 HRT 资料也已被人补上，**唯独 FTM 侧的用药、嗓音、手术三块无人占据**。这既是缺口，也是最清晰的切入机会。
